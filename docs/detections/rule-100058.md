# Rule 100058 — Suspicious PowerShell Script Block

| Field | Value |
|---|---|
| Data source | PowerShell Operational event 4104 |
| Rule anchor | Windows group (`if_group`), not private rule 91837 |
| Expected decoder | `windows_eventchannel` |
| Expected level | 10 |
| Evidence | `tested-private` |
| ATT&CK | T1059.001 — PowerShell |

The rule identifies `Invoke-Expression` or `IEX` in Script Block Logging. Positive fixture: a harmless synthetic script block containing the indicator. Negative fixture: a benign script block without it.

Investigate the complete script block, parent process, user, host, command line, downloads, encoded content, and child processes. Administrative tooling may legitimately use these functions. Tune by trusted signed script or constrained context, not a global keyword exclusion. Remove test scripts and verify no child process or persistence remains.
