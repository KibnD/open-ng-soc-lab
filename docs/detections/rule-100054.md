# Rule 100054 — Addition to Domain Admins

| Field | Value |
|---|---|
| Data source | Windows Security event 4728 |
| Expected decoder | `windows_eventchannel` |
| Expected level | 14 |
| Wazuh baseline | 4.8.2 |
| Evidence | `tested-private` (PT-04 PASS) |
| ATT&CK | T1098.007 — Additional Local or Domain Groups |

The rule identifies membership addition to the built-in Domain Admins group using group SID suffix `-512`. PT-04 added a disabled temporary account for three seconds, detected it, then removed it; rollback generated event 4729.

Positive fixture: event 4728 for group RID 512. Negative fixture: event 4728 for a non-privileged group. Investigate subject/member SIDs, change origin, ticket/change record, logon session, and subsequent privileged activity. Escalate any unauthorized addition. Reversible response is member removal after authorization, credential reset, and session review.
