# Rule 100052 — Windows event-log clearing

| Field | Value |
|---|---|
| Data source | Windows Security event log |
| Expected decoder | `windows_eventchannel` |
| Expected level | 12 |
| Wazuh baseline | 4.8.2 |
| Evidence | `tested-private`; PT-05 **NOT RUN** |
| ATT&CK | T1070.001 — Clear Windows Event Logs |

The capability detects security-relevant log clearing. PT-05 was intentionally not executed because clearing live logs is destructive; earlier private evidence supports the rule.

Use a minimized synthetic positive fixture and a normal log-management negative fixture. Do not clear operational logs for testing. Investigate actor, host, log channel, adjacent process creation, remote sessions, and gaps in telemetry. Legitimate maintenance or retention operations may match. Escalate unauthorized clearing; preserve remaining evidence before reversible containment.
