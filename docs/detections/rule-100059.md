# Rule 100059 — Service launches a command shell

| Field | Value |
|---|---|
| Data source | Windows System event 7045 |
| Parent dependency | Wazuh rule 61138 |
| Expected decoder | `windows_eventchannel` |
| Expected level | 12 |
| Evidence | `tested-private` |
| ATT&CK | T1543.003 — Windows Service |

The rule detects a newly installed service whose image path invokes `cmd`, `powershell`, or `pwsh`. The positive fixture contains a harmless disposable shell-based service; the negative fixture uses a normal executable path.

Investigate service name/path/account, signer, creator activity, remote administration, process tree, and persistence. Management products may use interpreters. After authorization, stop and delete a malicious or disposable service, remove its payload, and verify the service and persistence are absent.
