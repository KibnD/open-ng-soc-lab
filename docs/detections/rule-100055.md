# Rule 100055 — Successful RC4 Kerberos service ticket

| Field | Value |
|---|---|
| Data source | Windows Security event 4769 |
| Expected decoder | `windows_eventchannel` |
| Expected level | 12 |
| Wazuh baseline | 4.8.2 |
| Evidence | `tested-private` (PT-03 PASS) |
| ATT&CK | T1558.003 — Kerberoasting |

The heuristic selects successful (`0x0`) service-ticket requests using RC4 (`0x17`). PT-03 generated a controlled RC4 ticket and completed cleanup.

Positive fixture: matching RC4 event. Negative fixture: comparable AES ticket. Investigate service account, SPN, requesting host/account, ticket volume, encryption policy, and follow-on authentication. Legacy systems may legitimately use RC4. Tune approved legacy principals narrowly; do not suppress all RC4. Remove temporary SPNs/accounts and verify normal ticket encryption after testing.
