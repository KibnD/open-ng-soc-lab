# Rule 100057 — Repeated failed network logons

| Field | Value |
|---|---|
| Data source | Windows Security event 4625 |
| Parent dependency | Wazuh rule 60122 |
| Expected decoder | `windows_eventchannel` |
| Expected level | 10 |
| Correlation | Five failures from one source within 120 seconds |
| Evidence | `tested-private` |
| ATT&CK | T1110.001 — Password Guessing |

The positive test requires a stateful sequence of five failures sharing the source within 120 seconds. A negative test remains below threshold or varies the source. Static XML parsing cannot prove frequency semantics.

Investigate source system, targeted accounts, logon type, failure status, successful logons, lockouts, and asset ownership. Mistyped credentials, stale services, and scanners can match. Rate-limit or isolate only after confirming impact; unlock or reset disposable test accounts during cleanup.
