# Rule 100056 — Audited privileged Docker launch

| Field | Value |
|---|---|
| Data source | Linux sudo/audit command telemetry |
| Parent dependency | Wazuh rule 5402 |
| Expected decoder | `sudo` |
| Expected level | 12 |
| Wazuh baseline | 4.8.2 |
| Evidence | `tested-private` (PT-06 PASS) |
| ATT&CK | T1611 — Escape to Host |

The rule matches audited `sudo docker run --privileged` execution. PT-06 used a no-network, no-mount container executing `true`, then verified cleanup. A command match does not prove a successful launch or escape.

Negative fixture: ordinary non-privileged container command. Investigate user, sudo session, image provenance, mounts, capabilities, network, container state, and host changes. Approved maintenance can match. Stop/remove the container after authorization and verify no mount, network, process, or persistence remains.
