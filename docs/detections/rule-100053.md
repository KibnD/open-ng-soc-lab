# Rule 100053 — Synthetic CloudTrail CreateAccessKey

| Field | Value |
|---|---|
| Data source | Synthetic CloudTrail JSON read by Wazuh `localfile` |
| Expected decoder | `json` |
| Expected level | 12 |
| Wazuh baseline | 4.8.2 |
| Evidence | `simulated` |
| ATT&CK | T1098.001 — Additional Cloud Credentials |

This detects a synthetic `CreateAccessKey` management event. It does not prove real AWS ingestion, GuardDuty integration, or use of the `wazuh-aws` module.

Positive fixture: synthetic `CreateAccessKey`; negative fixture: a benign synthetic read-only event. Investigate actor ARN, source address, user agent, request parameters, MFA context, and surrounding IAM changes. Legitimate key rotation may match. In a real environment, verify ownership before disabling a key. Delete any local synthetic event file after testing.
