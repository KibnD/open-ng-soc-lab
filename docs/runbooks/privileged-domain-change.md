# Runbook — Privileged domain change

Triage event 4728, subject/member SIDs, target group, source host, logon session, authorized change record, and subsequent activity. Planned identity administration is the main false-positive source.

Escalate unauthorized changes or suspicious authentication. Preserve evidence before removing membership. With approval, remove the member, reset exposed credentials, revoke sessions, and inspect related changes. Validate event 4729, effective membership, authorized access, and absence of persistence.
