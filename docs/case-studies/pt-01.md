# PT-01 — Network telemetry pipeline

**Status:** PASS with private evidence. **Public reproduction:** pending.

Objective: verify controlled Suricata-format telemetry from the pfSense path reaches Wazuh and matches rule 100051. The initial contained request returned HTTP 301 and did not create a Suricata event, so a controlled Suricata-format replay was used. A separate tagged marker confirmed UDP/514 transport after pfSense `syslogd` was restarted once Wazuh was healthy.

This proves the tested pipeline and matching behavior, not real exploitation. Cleanup required no persistent target change. Public reproduction awaits the audited decoder, fixture, and `wazuh-logtest` result.
