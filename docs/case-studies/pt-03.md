# PT-03 — RC4 Kerberos service ticket

**Status:** PASS with private evidence. **Public reproduction:** pending fixtures.

A controlled account requested a successful RC4 (`0x17`) Kerberos service ticket. Event 4769 matched rule 100055; an AES comparison served as the negative control. Temporary test state was removed and normal behavior checked.

This validates a heuristic in the isolated lab, not a claim that every RC4 ticket is malicious. Legacy compatibility is a known false-positive source.
