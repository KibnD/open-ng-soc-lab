# Evidence policy

Public claims use these controlled states:

- `implemented-private`: present in the private lab; public export is incomplete.
- `tested-private`: exercised successfully with evidence retained privately.
- `reproduced-public`: a public fixture and assertion passed in a documented public test.
- `documented-only`: described but not reproduced.
- `simulated`: based on synthetic telemetry or a safe simulation.
- `target`: planned work only.

Only deterministic public execution can earn `reproduced-public`. Screenshots support context but never replace fixtures and assertions.

Private reports, raw logs, original screenshots, credentials, personal data, operational identifiers, company-branded material, and confidential topology remain outside this repository. Public evidence must be minimized, synthetic or irreversibly sanitized, technically useful, and reviewed for metadata and redistribution rights.
