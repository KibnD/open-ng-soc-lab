# Support policy

This pre-release educational project provides no production support, warranty, SLA, incident-response service, or compatibility guarantee.

Use GitHub issues only for reproducible, nonsensitive questions and defects. Include environment/version, sanitized reproduction steps, expected and observed behavior, validation output, and relevant limitations. Do not attach raw logs or screenshots until reviewed for secrets and personal data.

Only versions listed in [`detections/wazuh/VERSION_SUPPORT.md`](detections/wazuh/VERSION_SUPPORT.md) have a stated test status. Security reports follow [SECURITY.md](SECURITY.md).
