# Security Policy

## Supported versions

No released version is currently supported. The repository is publicly visible but remains pre-release and not production-ready.

## Reporting a vulnerability

Do not open a public issue containing a vulnerability, credential, private identifier, or sensitive evidence. Until GitHub private vulnerability reporting is enabled, contact the maintainer through the private contact method shown on the maintainer's GitHub profile; do not send sensitive details until a private channel is confirmed.

Include a concise description, affected path/version, reproduction conditions, impact, and a safe proof of concept. Never include live secrets or data belonging to another party.

## Scope and safe use

This project is an educational laboratory reference and is not production-ready. Simulations must run only in isolated, owned, or explicitly authorized environments. Stop if scope, authorization, containment, or rollback readiness is uncertain.
